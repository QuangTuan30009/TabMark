# 🚀 Hướng Dẫn Cài Đặt TabMark Chrome Extension (15 Giây)

Tiện ích mở rộng **TabMark Extension** cho phép bạn lưu bất kỳ trang web nào đang đọc vào bảng Kanban của TabMark chỉ với **1-click** hoặc phím tắt **`Alt + S`**.

---

## 📌 Các bước cài đặt vào Chrome / Edge / Brave:

### Bước 1: Mở trang quản lý Extension trên trình duyệt
- Trên Google Chrome / Brave: Truy cập `chrome://extensions/`
- Trên Microsoft Edge: Truy cập `edge://extensions/`

### Bước 2: Bật "Chế độ dành cho nhà phát triển" (Developer mode)
- Gạt công tắc **Developer mode** (ở góc trên cùng bên phải) sang vị trí **BẬT (ON)**.

### Bước 3: Tải Extension vào trình duyệt
- Bấm vào nút **"Tải tiện ích đã giải nén" (Load unpacked)** ở góc trên bên trái.
- Chọn thư mục **`extension`** nằm trong thư mục dự án:
  `c:\Users\taqua\OneDrive\Major\Major\7\EXE101\tabmark-react-pages\extension`

---

## 🎯 Cách sử dụng:

1. **Cách 1 (Nhanh nhất)**: Bấm phím tắt **`Alt + S`** trên bất kỳ trang web nào.
2. **Cách 2**: Bấm vào icon **🔖 TabMark** trên thanh công cụ của trình duyệt.
3. **Cách 3 (Chuột phải)**: Click chuột phải vào bất kỳ đâu trên trang web $\to$ Chọn **"🔖 Lưu trang này vào TabMark"**.

Popup sẽ tự động:
- Lấy tiêu đề trang và URL.
- Cho phép bạn chọn nhóm (Collection) muốn lưu.
- Chọn tag nhanh (`#dev`, `#design`, `#tools`, `#docs`).
- Bấm **"Lưu vào TabMark"** $\to$ Dữ liệu sẽ xuất hiện ngay trên Dashboard!
