# 🚀 TabMark Extension - Smart Bookmark Saver

Tiện ích mở rộng chính thức **TabMark Extension** cho phép bạn lưu bất kỳ trang web nào đang đọc vào bảng Kanban của TabMark chỉ với **1-click**, phím tắt **`Alt + S`**, hoặc menu chuột phải.

---

## 📥 1. Cài Đặt Trực Tiếp Từ Microsoft Edge Add-ons (Khuyên dùng)

Tiện ích đã được phát hành chính thức trên kho ứng dụng:
👉 **[Tải TabMark trên Microsoft Edge Addons](https://microsoftedge.microsoft.com/addons/detail/tabmark-smart-bookmark-/dldjaanefkaicpcdaglljeoofcabngnk)**

> **Mẹo:** Tiện ích này tương thích hoàn toàn với tất cả trình duyệt Chromium như **Microsoft Edge, Google Chrome, Cốc Cốc, Brave**. (Trên Chrome, bạn chỉ cần bật tùy chọn *"Cho phép tiện ích từ các cửa hàng khác"* là có thể cài đặt trực tiếp từ link trên).

---

## 🛠️ 2. Cài Đặt Thủ Công Dành Cho Lập Trình Viên (Developer Mode)

Nếu bạn muốn chỉnh sửa mã nguồn hoặc chạy thử phiên bản nội bộ:

### Bước 1: Mở trang quản lý Extension trên trình duyệt
- Trên Microsoft Edge: Truy cập `edge://extensions/`
- Trên Google Chrome / Brave: Truy cập `chrome://extensions/`

### Bước 2: Bật "Chế độ dành cho nhà phát triển" (Developer mode)
- Gạt công tắc **Developer mode** (ở cột trái trên Edge hoặc góc trên bên phải trên Chrome) sang **BẬT (ON)**.

### Bước 3: Tải Extension vào trình duyệt
- Bấm vào nút **"Tải tiện ích đã giải nén" (Load unpacked)**.
- Chọn thư mục **`extension`** trong mã nguồn dự án.

---

## 🎯 Hướng Dẫn Sử Dụng

1. **Cách 1 (Nhanh nhất)**: Bấm tổ hợp phím **`Alt + S`** trên bất kỳ trang web nào bạn đang xem.
2. **Cách 2**: Bấm vào biểu tượng **🔖 TabMark** trên thanh công cụ của trình duyệt.
3. **Cách 3 (Menu ngữ cảnh)**: Nhấp chuột phải vào bất kỳ vị trí nào trên trang web $\to$ Chọn **"🔖 Lưu trang này vào TabMark"**.

### Tính Năng Popup:
- Tự động nhận diện tiêu đề trang web và URL hiện tại.
- Đồng bộ danh sách nhóm (Collections) từ tài khoản TabMark của bạn.
- Chọn nhanh thẻ phân loại (`#dev`, `#design`, `#tools`, `#docs`).
- Tự động đồng bộ ngay lập tức sang ứng dụng web TabMark mà không cần tải lại trang.
